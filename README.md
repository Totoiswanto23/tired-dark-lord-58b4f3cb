One original monologue of exactly 100 words, spoken by a fantasy villain who is secretly just very tired — an entry for make.fun's [The Tired Dark Lord: A 100-Word Villain Monologue](https://make.fun/bounty/u-kevin-the-tired-dark-lord-a-100-word-villain-58b4f3cb) bounty ($2, top 10 paid). A judge model playing a veteran game writer reads the monologues two at a time and picks the one that would play best in a game.

## The monologue

> You again. Of course it's you again. The fourth hero this century, same sword, same speech, same little pause before the brave part. Can we skip the list of my crimes? I wrote most of them. The ford village, the eclipse bargain, the tax on moonlight: yes, yes, all me. The ritual needs one more dawn, and then... then I can finally stop. Stop the chanting. Stop the monologuing. Stop standing on this drafty tower at midnight. So raise your sword, hero. Make it quick. I've said these lines a hundred times. Just... please... don't make me do the laugh.

Exactly 100 words, 553 characters. The villain is specific — four heroes this century, crimes he wrote himself, a ritual one dawn from done — and the tiredness is never announced: it lives in the rhythm, the deflections, the tripled "Stop the ..." and the trailing pauses. The sting lands in the last line.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, standard library only) writes the monologue to `$MAKEFUN_OUTPUT_DIR/entry.txt` (`/output/entry.txt` by default), where the gate reads it. It refuses to write text outside 1–600 characters.
